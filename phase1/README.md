# SmartFile – File Compression and Decompression

SmartFile is a C++ application that uses **Huffman Coding** for lossless file compression and decompression.

## Features
- Huffman Coding using Binary Trees and Min-Heap.
- Bit-level file handling.
- Custom `.sfile` format.
- RAW mode when compression is not beneficial.
- Displays file size and storage savings.

## Technologies Used
- C++
- Data Structures and Algorithms (DSA)
- Object-Oriented Programming (OOP)
- Binary File Handling
